This folder contains placeholder textures for the game.

Required textures:
1. grass.jpg - Ground texture for terrain
2. asphalt.jpg - Road texture
3. cloud.png - Cloud texture (with transparency)

These textures should be added to the assets/textures directory.

For development, you can use free textures from sites like:
- textures.com
- cc0textures.com
- opengameart.org

Be sure to check the license terms before using any textures in your project.
