This folder contains audio files for the game.

Required audio files:
1. engine_loop.mp3 - Engine sound that will loop while driving
2. wind.mp3 - Ambient wind sound
3. road_noise.mp3 - Road/tire noise

These audio files should be added to the assets/audio directory.

For development, you can use free sound effects from sites like:
- freesound.org
- zapsplat.com
- soundbible.com

Be sure to check the license terms before using any audio in your project.
